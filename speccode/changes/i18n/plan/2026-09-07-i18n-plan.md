# 多国语言支持(i18n)Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use /speccode:subagent-driven-development
> (recommended) or /speccode:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地语言模型 v4——交互镜像用户语言(无静默兜底),工件语言由 `config.language` 显式固定(BCP-47 自由 tag,缺失=跟随交互),门面转英文,lib 语言中立。

**Architecture:** 四层各自落地、互不耦合:引擎层加 `validateLanguage` 纯函数与 `buildIndex` 标题参数化(全部 TDD,lib 零语言字符串);命令层 24 个 description 转英 + 9 个产工件命令加语言守护段;门面 2 个 json 转英;守卫测试防「全程中文交互」回潮。

**Tech Stack:** Node ≥ 24 纯 ESM、`node --test`(glob 形式)、零第三方依赖、真实临时 git 仓库测试(`tests/helpers/tmprepo.mjs`)。

## Global Constraints

- Node ≥ 24,纯 ESM,零第三方依赖(仅 `node:` 内置模块)
- 全量测试必须 glob 形式 `node --test ./tests/*.test.mjs`(裸目录形式在 Node v24 报 MODULE_NOT_FOUND);单用例 `node --test --test-name-pattern="<name>" <file>`
- 涉及 git 的测试用 `tests/helpers/tmprepo.mjs` 的 `makeRepo()` 建真实临时仓库,用完 `rmSync` 清理
- 写 verb 一律 `--json-stdin`;未知 verb 或抛错 → `{ok:false, error}` + exit 1
- **lib 语言中立**:`lib/` 内不得出现任何自然语言文本(含默认值);语言文本只存在于命令 prose 与测试数据
- 命令正文裸调 `speccode <verb> --cwd .`;prose 禁 `speccode.mjs` 形态、绝对路径、`${CLAUDE_PLUGIN_ROOT}`、宿主专属 token(AskUserQuestion、TodoWrite、subagent_type、宿主指令文件名)
- `skills/*/SKILL.md` 正文保持中文;仅 frontmatter `description` 转英文
- `validateLanguage` 契约(逐字):BCP-47 语言标签——主子标签 2-3 个字母(接受任意大小写输入,归一化为小写返回),可附连字符分隔的后续子标签(每段 2-8 个字母数字);非法(非字符串/格式不符)返回 `null`
- mode index 契约(逐字):stdin payload 必填 `heading`(非空字符串);缺失或非字符串 → `{ok:false, error:'mode index requires heading'}`
- detect-host 用法报错串(逐字):`detect-host: --host requires a host id value`
- 原子写:config/memory 一律经 verb(`write-config`/`write-memory`),绝不手写 `.speccode/` 下文件
- 提交信息 conventional commits;文档类用 `docs(speccode):` 前缀
- 本计划不修改 `speccode/changes/i18n/propose/proposal.md` 的 frontmatter `tier` 字段

// BCP-47 language tag: 2-3 letter primary subtag (case-insensitive, normalized
// to lowercase) plus optional hyphen-separated subtags (2-8 alphanumerics
// each). Returns the normalized tag, or null for anything malformed.
// 语言中立:合法性与归一化在此止步,lib 不含任何具体语言文本。
export function validateLanguage(value) {
  if (typeof value !== 'string') return null;
  const tag = value.toLowerCase();
  return /^[a-z]{2,3}(-[a-z0-9]{2,8})*$/.test(tag) ? tag : null;
}
```

export function buildIndex(entries, heading) {
  if (typeof heading !== 'string' || heading.trim() === '') {
    throw new TypeError('buildIndex requires a heading string');
  }
  const lines = [`# ${heading}`];
  for (const { section, items } of entries) {
    lines.push('', `## ${section}`);
    for (const { title, file, summary } of items) {
      lines.push(`- ${title} → ${file}:${summary}`);
    }
  }
  return `${lines.join('\n')}\n`;
}
```
